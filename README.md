# Portofolio Muhammad Farhan (Next.js)

Next.js 14 (App Router) + TypeScript + Tailwind CSS + react-icons.

## Menjalankan

```bash
npm install
npm run dev        # http://localhost:3000
```

## Build (static export)

```bash
npm run build      # hasil di folder ./out
```

## Deploy ke Cloudflare Pages

- Build command: `npm run build`
- Build output directory: `out`

## Edit konten

Semua teks, sertifikasi, keahlian, dan daftar proyek ada di `data/site.tsx`.

## Foto profil

Ganti `public/profile.jpg` dengan foto kamu sendiri.
